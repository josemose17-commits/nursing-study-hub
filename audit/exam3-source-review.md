## Current-source distinctions and corrections

These updates supersede the corresponding older teaching statements in the affected notes/practice. They do not assert that every textbook recommendation has been updated to current practice.

| Issue | Correction and connected locations |
| --- | --- |
| CGM calibration/confirmation | Replaced universal twice-daily calibration with device-specific instructions and BGM backup for discordance/other indicated situations. Revised the existing low-alarm question to explicitly describe a stable client, discordant reading, available meter and device instructions. Notes, Quick bullets, explanatory card, glossary and mechanism node agree. |
| DKA with type 2 or lower glucose | Removed the claim that type 2 excludes DKA. Distinguished the book's typical table values from diagnostic rule-out thresholds; added SGLT2-associated euglycemic DKA practice. |
| Potassium before insulin | Added current adult consensus guidance to delay insulin for K⁺ < 3.5 mmol/L until K⁺ > 3.5. Corrected the unfolding case that previously continued insulin at 3.4, its planning step, trend question and prioritization feedback. |
| DKA resolution | Uses plasma ketones with pH/bicarbonate rather than gap closure alone. Added a plasma ketone result to the hypothetical case so its evaluation question has enough information. Updated linked recall/explanation/node content. |
| MODY | Replaced automatic type-1-equivalent/insulin assumptions with subtype-specific management. |
| Sick-day drugs | Distinguished essential basal insulin from other drugs that may need a prescribed temporary interruption; removed blanket instructions to continue every diabetes medication. |
| H. pylori | Kept the older Table 47.1 examples explicitly labeled; added current ACG regimen/susceptibility and test-of-cure distinctions. Corrected the erroneous explanation that all triple therapy is simply quadruple therapy without bismuth, and synchronized the drug-class/explanatory cards. |
